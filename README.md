Stock Assistant
===============

AI-assisted stock research platform for Indian equities.

Features
--------
• Technical analysis
• Fundamental analysis
• Market heatmap
• Backtesting
• RL/PPO research
• Out-of-sample validation

Tech Stack
----------
Python
Streamlit
Pandas
NumPy
Plotly
yFinance
Stable-Baselines3

Status
------
Active development.

The RL trading agent is experimental and
has not passed the production validation gate.
